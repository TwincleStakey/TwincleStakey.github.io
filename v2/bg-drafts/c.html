2.3핵심 시스템

2.3.1

멀티 판정과 지연 보상

맞는 쪽이 판정하고, 공격자가 본 자리로 되감아 잰다.

  • 맞음 · 막기 · 튕겨내기는 맞는 쪽 PC가 정한다
  • 다른 PC의 공격은 그 화면이 나를 그리던 시각만큼 위치를 되감는다
  • 불꽃 · 소리는 바로, 체력은 확정이 올 때만
문제

게스트로 하면 화면에선 맞은 비도가 피해 없이 지나갔다.

원인

맞는 쪽이 판정하는데 지연 보상이 없었다.

해결

공격자가 나를 그리던 지연만큼 위치를 되감아 잰다.

float ViewDelayOf(Duelist attacker)
{
    // 방장 몸: 게스트 PC 보간 버퍼(50ms + 3틱)만큼 더 늦게 그려진다
    float delay = IsServer ? attackerOneWay + 0.05f + 3f / 60f : OneWay + attackerOneWay;
    return Mathf.Min(MaxRewind, delay);
}
